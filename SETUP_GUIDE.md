# Grace Music Academy - Complete Setup Guide

## 📱 How to Install on Your Devices (Current Cloud Version)

### MacBook / Windows / Linux
1. Open Chrome/Safari browser
2. Go to: `https://pianopulse.preview.emergentagent.com`
3. Login with your credentials
4. Bookmark the page for quick access

### iPad / iPhone
1. Open Safari browser
2. Go to: `https://pianopulse.preview.emergentagent.com`
3. Tap the Share button (square with arrow)
4. Tap "Add to Home Screen"
5. Name it "Grace Music" and tap Add
6. Now you have an app icon on your home screen!

### Android Phone/Tablet
1. Open Chrome browser
2. Go to: `https://pianopulse.preview.emergentagent.com`
3. Tap the 3-dot menu (top right)
4. Tap "Add to Home screen"
5. Name it "Grace Music" and tap Add
6. Now you have an app icon!
